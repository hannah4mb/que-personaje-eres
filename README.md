# ¿Qué personaje eres?

Aplicación web interactiva tipo quiz desarrollada con HTML5, CSS3 y JavaScript vanilla, diseñada para descubrir a qué personaje te pareces respondiendo cinco preguntas dinámicas.

## Proceso Realizado
- **Estructura:** Organización de archivos en carpetas (`/img`, `index.html`, `style.css`, `script.js`).
- **Desarrollo:** Implementación de pantallas dinámicas mediante manipulación del DOM en JavaScript y estilos adaptativos con CSS.
- **Despliegue:** Configuración local en servidor web Apache mediante Virtual Host.
